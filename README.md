# passive-ac-ammeter-and-wireless-reader

Standalone LP-MSPM0G3507 firmware generated by `prepare-nuedc`.

```sh
cargo build --release
cargo run --release
```

The template discards Embassy's ownership tokens after initialization and
steals its fixed LED pin. Peripheral crates follow the same convention; check
their documented fixed pins for conflicts before calling an unsafe constructor.

The runner expects `pyocd` and the TI MSPM0G device pack to be installed.
