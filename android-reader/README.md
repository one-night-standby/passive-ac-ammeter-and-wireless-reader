# 无线读表器 Android App

按照赛题“基本模式和自动模式读取电流表读数”的要求实现。

## 功能

- App 启动后自动搜索，发现第一个 HC-42 后立即连接，无需设备列表操作。
- 基本模式：保持一对一连接，点击“手动读取”采集下一帧数据。
- 自动模式：一键启动，搜索无线覆盖范围内名称匹配的全部电流表，每 2 分钟自动采集一轮。
- 采集间隔：默认 2 分钟，可通过主界面按键设置为 10 秒、30 秒或 1～5 分钟，设置会持久保存。
- 地址码切换：在 `00`～`15` 之间切换当前查看的电流表。地址码由电流表拨码开关设置，App 不向电流表发送控制命令。
- 数据记录：使用手机内部 SQLite 持久保存最近 1000 条，包含读取时间、地址、电流值以及正常、低限、超限或离线状态。
- 历史与趋势：显示最近 50 条历史记录，并按当前地址绘制最近 120 条有效电流数据趋势。
- 历史清除：经二次确认后清除全部历史读数和已登记电流表。

App 不提供原始数据对话、HEX 收发、设备手动选择和阈值设置。

## 固定通信参数

| 项目 | 值 |
| --- | --- |
| BLE Service | `0000FFE0-0000-1000-8000-00805F9B34FB` |
| Notify Characteristic | `0000FFE1-0000-1000-8000-00805F9B34FB` |
| 自动采集周期 | 120 秒 |
| 单轮扫描窗口 | 8 秒 |

M0 数据帧：

```text
METER_TEST,ADDR=01,CURRENT_MA=1234,STATUS=NORMAL\r\n
```

## 构建

需要 JDK 17、Android SDK Platform 35 和 Build Tools 35：

```powershell
cd android-reader
gradle assembleDebug
```

调试 APK 输出到：

```text
app/build/outputs/apk/debug/app-debug.apk
```
